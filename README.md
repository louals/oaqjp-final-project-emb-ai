## Getting Started

### Prerequisites

Make sure you have the tools required for this stack installed (e.g. Python 3.10+, Node.js 18+, or Android Studio).

### Installation & Usage

```bash
git clone https://github.com/<your-username>/oaqjp-final-project-emb-ai.git
cd oaqjp-final-project-emb-ai
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt   # if present
python main.py
```
> Replace `main.py` with the project's entry script if different.
